# Дизайн-аудит: исходные наблюдения

Дата: 2026-08-12

## Экран входа в опубликованной версии

- Экран ориентирован на узкую мобильную колонку, расположен на очень светлом лавандовом фоне.
- Основной контент собран в белой скруглённой карточке с мягкой тенью.
- Иерархия: небольшой брендинг `FINANCE`, заголовок `Вход`, поясняющий текст, подпись поля, email-поле и основная кнопка `Получить код`.
- Сильная сторона: сценарий предельно компактен и хорошо подходит для PWA.
- Возможности улучшения: усилить визуальную систему бренда и контраст смысловых уровней, сделать акцентные состояния и поверхности более выразительными, нормализовать ритм отступов и подготовить общие токены для всех экранов.

## Контекст проекта

- Это русскоязычный PWA-калькулятор личных финансов в BYN с захватом операций, историей, категориями и месячной сводкой.
- Стек: Next.js 16, React 19, TypeScript, Tailwind CSS 4.
- Основные UI-компоненты расположены в `src/components`; ключевые экраны — capture, history, month, categories и login.

## Финальная визуальная проверка

Локальная версия экрана входа успешно отрисована после редизайна. На широком экране PWA-сцена теперь показана как аккуратная узкая панель с крупными скруглениями, белой полупрозрачной карточкой и мягким градиентным фоном. Новая иерархия хорошо считывается: знак `Br`, надпись «Личные финансы», заголовок, пояснение, поле и основная кнопка последовательно ведут пользователя к действию. Контраст текста, границы поля и насыщенная индиго-кнопка достаточны для быстрого восприятия.
